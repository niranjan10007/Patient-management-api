Built a full-stack patient management application using Python and FastAPI to provide a RESTful API for managing patient records and healthcare-related information.

• Developed REST API endpoints for creating, retrieving, updating, and deleting patient records (CRUD).
• Used Pydantic models for request validation, structured data handling, and API schema definition.
• Implemented API documentation using Swagger/OpenAPI, making endpoints easy to test and understand.
• Built a Streamlit-based interface to interact with the backend API and perform patient management operations.
• Implemented data handling and validation to maintain consistent and reliable patient records.
• Tested API endpoints and verified different request and response scenarios during development.

Tech: Python | FastAPI | Pydantic | REST API | Swagger/OpenAPI | Streamlit
